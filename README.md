# 🤖 Projeto em destaque — Omni

<div align="center">

### Atendimento inteligente e triagem automatizada de chamados de TI

</div>

O **Omni** é uma solução de atendimento interno baseada em **Inteligência Artificial**, desenvolvida para auxiliar funcionários na resolução e no direcionamento de solicitações de TI.

A solução automatiza o primeiro atendimento, orientando o usuário na resolução de problemas simples e, quando necessário, coletando informações, classificando a solicitação e encaminhando o chamado para a equipe responsável.

### 🎯 Objetivo

Reduzir chamados simples, repetitivos ou direcionados incorretamente, tornando o suporte de TI mais:

**Rápido • Organizado • Inteligente • Eficiente**
